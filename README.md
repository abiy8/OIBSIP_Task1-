# Iris Flower Classification

Visualize sepal dimensions, split examples 80/20 with `random_state=0`, and fit a one-neighbor KNN classifier to flower variety.

**Stack:** Python · pandas · scikit-learn · Jupyter

## Run locally

```bash
git clone https://github.com/abiy8/OIBSIP_Task1-.git
cd OIBSIP_Task1-
python -m venv .venv
# Activate .venv for your operating system.
pip install jupyter pandas numpy matplotlib plotly scikit-learn
jupyter notebook
```

Open `Iris.ipynb` and run cells in order from the repository directory. Input data is included in `iris.csv`.

## Context and limitations

Oasis Infobyte task / learning project. This is an introductory classification exercise using one dataset and one split, not a deployed classifier. Cross-validation and feature scaling are useful follow-up work.
